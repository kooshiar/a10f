# small-world web

Static pages. Deploy the folder as-is (Cloudflare Pages, Vercel). Set the server URL in `config.js`.

- `sandbox.html`  the box: composition, temperature, force model
- `index.html`    search any molecule or PDB entry
- `gallery.html`  ten molecular machines
- `deck.html`     the deck
- `tools/build_structures.py` regenerates `data/*.pdb` (needs `ase rdkit`)
